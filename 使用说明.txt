ImageJ 正畸口腔影像分析（简体中文汉化版）
=============================================
版本：基于 ImageJ 1.54u9 源码（imagej/ImageJ master）汉化重构
适用：Windows 10 / 11（64 位），自带 Java 运行时，无需另装 JDK/JRE
汉化：基耶杰

一、怎么启动
------------
双击 ImageJ-Prosth-CN.exe 即可。

首次启动 Windows 防火墙可能弹窗询问网络访问，这是 ImageJ 自身用于"防止重复启动"
的本地端口探测，选「允许」或「取消」都不影响使用。

二、这次改了什么
----------------
1) 全界面简体中文（正畸/口腔语境的译法）
   - 8 个主菜单 + 全部子菜单共 300+ 条命令，逐条术语校对：
     Analyze Particles → 颗粒分析（牙体/骨小梁计数）
     Feret's diameter → 费雷特直径（最大卡尺径）
     Area fraction → 面积占比
     Integrated density → 积分密度（累积光密度）
     Watershed → 分水岭   Skeletonize → 骨架化   Threshold → 阈值
     并附头影测量常用点：蝶鞍点 S、鼻根点 N、眶点 Or、耳点 Po、颏下点 Me、
     下颌角点 Go、A 点 / B 点、颏前点 Pog、颏顶点 Gn、前/后鼻棘 ANS/PNS 等。
   - 通用对话框（GenericDialog）统一汉化：确定/取消/帮助/预览、字段标签、
     复选框、字号、比例尺、测量参数等；是/否/取消与消息框一并处理。
   - 命令查找器（Plugins ▸ Find Commands…）支持中文检索，
     输入"阈值""颗粒分析""比例尺"就能定位到对应命令。
   - 右键菜单全部汉化并改为自绘：
       · 图像窗口右键（显示信息/属性/重命名/测量/直方图/复制图像/原始比例/录制…）
       · 选区右键（ROI 属性、添加到叠加层、添加到 ROI 管理器、创建蒙版…）
       · 工具栏长按/右键（矩形、圆角矩形、旋转矩形、椭圆、点、多点、直线、
         折线、手绘线、箭头；缩放菜单；前景/背景色；工具集切换）
       · 结果表 / 日志窗口的菜单栏与右键菜单（另存为、重命名、查找、汇总、
         分布、设置测量参数、排序、绘图、字体、等宽字体、抗锯齿…）
       · ROI 管理器右键菜单（绘制、填充、拆分、合并、多曲线绘图、选项…）
   - 状态栏操作提示全部汉化：点选工具时底部那行说明（矩形 / 椭圆 / 多边形 /
     手绘 / 直线 / 折线 / 手绘线 / 点 / 多点 / 魔棒 / 文本 / 放大镜 / 抓手 /
     取色器 / 角度）已改为中文，并保留"按住 Alt 或长按要求切换""双击进行设置"
     等操作提示；启动时显示的"多少条命令、多少个宏"也已中文化。
   - 其余窗口的对话框标题、按钮、下拉选项、提示段落（约 1500 条词条）一并汉化，
     内部命令名仍保持英文，不影响宏与插件。

2) 中文界面不破坏兼容性（关键设计）
   - 中文只做"显示层"替换，内部命令名、菜单路径、插件表键值、快捷键表
     全部保持英文。因此：
       · 宏 run("Open...")、run("Make Binary") 照常工作
       · 原有 plugins 目录里的插件、macros 目录里的宏照常挂载
       · 结果表列名（Area、Mean 等）仍为英文，第三方脚本不受影响

3) 4K / 高 DPI 适配
   - 自动识别显示环境：若 JVM 已按系统 DPI 缩放（Java 9+ 默认），ImageJ 不再重复放大，
     避免"双重放大"导致的字大如斗；若系统缩放被关闭，则按屏幕 DPI/分辨率自行放大。
   - 菜单、状态栏、对话框、工具栏按钮统一按缩放系数计算，不再出现模糊小字。
   - 手动微调：Edit ▸ Options ▸ Appearance… 里的 "界面缩放（0.5-3.0）"，
     设一次即写入 IJ_Prefs.txt，后续启动沿用你的设置。
   - 默认堆内存 4 GB（-Xmx4g），便于处理全景片、CBCT 重建的多层数据。

4) 外观
   - 菜单与状态栏优先使用「微软雅黑 UI」，中文笔画更清晰。
   - 菜单栏改为自绘（Swing）实现：Windows 原生菜单的行高是系统固定的，
     字号一放大，中文字就会上下叠在一起。自绘后行高、左右留白都随字号自动伸缩，
     4K 屏把字放大到 2 倍也不会挤成一团，快捷键列右对齐。
   - 重新绘制了应用图标（牙弓 + 测量标尺），避免沿用老显微镜图标在小尺寸下糊成一团。

三、怎么用（正畸/口腔常见流程）
------------------------------
· 打开影像：File ▸ Open…（DICOM 单张），或 File ▸ Import ▸ Image Sequence…（多张）
· 设定比例尺（做测量必做）：
  Analyze ▸ Set Scale… → 填"像素距离"和"已知实际距离"（如 10 mm），单位填 mm
· 长度/角度测量：选直线工具沿标志点连线 → Analyze ▸ Measure（M 键）；
  角度用 分析 ▸ 工具 ▸ 角度工具 三点定义，结果表自动出 Angle 列
· 骨密度/灰度比较：Analyze ▸ Set Measurements… 勾选 平均灰度值、积分密度、面积
· 感兴趣区统计：Analyze ▸ Analyze Particles…（勾选 面积、周长、费雷特直径、
  最小外接矩形，可导出"颗粒分析"结果表做牙体/骨小梁计数）
· 头影测量：先用 Image ▸ Properties… 设定像素尺寸与单位，
  再用点工具标注标志点，用 Analyze ▸ Tools ▸ Save XY Coordinates 导出坐标
· 批量处理：Process ▸ Batch ▸ Macro…，或 Plugins ▸ Macros ▸ Record… 录制后批跑
· 找不到菜单？Plugins ▸ Find Commands…（Ctrl+L 可自定义快捷键）直接搜中文

四、目录说明
------------
ImageJ-Prosth-CN.exe   启动器（自带运行时）
app/ij-zh.jar          汉化后的 ImageJ 主程序
app/ij-zh.jar 内 ij/i18n/IJ_Lang_zh_CN.txt   语言包（Tab 分隔：英文<TAB>中文）
runtime/               精简 JRE（约 98 MB，已含 jdk.localedata，保证中文正常渲染）

自定义词条：把 IJ_Lang_zh_CN.txt 复制到 exe 同目录，改完重启程序即可覆盖内置词条；
改错直接删掉该文件即可回到内置版本。修改时请勿改左侧英文，只改右侧中文。

五、已知边界
------------
· 插件自己弹出的说明文字、错误提示（代码里硬编码的长句子）仍为英文，
  这类文本量极大且随插件变化，未纳入语言包。
· 少数专有名词保留英文（文件格式 TIFF/GIF/JPEG/DICOM、脚本语言
  BeanShell/Python/Java、示例里的 Games/2048、目录名 ImageJ），属有意保留。
· 第三方插件（.jar）的菜单项默认显示英文，可把其菜单名加入语言包实现汉化。
· 安装新插件请放在程序目录下的 plugins 文件夹（首次运行会自动创建）。
· 本包未做代码签名，SmartScreen 可能提示"未知发布者"，选择"仍要运行"。
